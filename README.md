# WEN Detailing — сайт детейлинг-студии (демо)

Демонстрационный сайт вымышленной детейлинг-студии в Воронеже.
Форма записи отправляет заявки в [WenLeadAI](../wenleadai) → уведомление менеджеру в Telegram.

Чистые HTML, CSS и JavaScript — без сборки и зависимостей.

## Запуск локально

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080. Чтобы форма работала, должен быть запущен WenLeadAI
(`npm run dev` и `npm run worker` в папке `wenleadai`).

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка: первый экран, услуги, цены, работы, преимущества, запись, контакты |
| `styles.css` | стиль: цвета, шрифты, анимации, адаптация под телефон |
| `main.js` | меню, анимации появления, цены по классу авто, слайдер «до/после», отправка формы |
| `config.js` | адрес WenLeadAI и ключ формы |
| `hero3d.js` | 3D-сцена первого экрана: Porsche 911 в детейлинг-боксе, вращение 360°, смена цвета |
| `models/porsche-911.glb` | 3D-модель, сжатая с 19 до 2,5 МБ (meshopt + WebP) |
| `vendor/three/` | библиотека three.js r170 — лежит в проекте, чтобы не зависеть от CDN |

## Перед запуском для реального клиента

- Заменить демо-данные: название, адрес, телефон, цены, фото работ.
- В `config.js` указать адрес WenLeadAI на сервере и ключ формы клиента.
- Добавить домен сайта в `allowedOrigins` формы в WenLeadAI.
- Шрифты загрузить на свой сервер (сейчас — Google Fonts).
- Политика конфиденциальности и текст согласия — от юриста.
